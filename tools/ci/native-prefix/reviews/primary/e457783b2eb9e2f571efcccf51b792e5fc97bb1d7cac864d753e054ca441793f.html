FormatNumericRange ( _numberFormat_: an Intl.NumberFormat, _x_: an Intl mathematical value, _y_: an Intl mathematical value, ): either a normal completion containing a String or a throw completion

description
1. Let _parts_ be ? PartitionNumberRangePattern(_numberFormat_, _x_, _y_). 1. Let _result_ be the empty String. 1. For each element _part_ of _parts_, do 1. Set _result_ to the string-concatenation of _result_ and _part_.[[Value]]. 1. Return _result_.
