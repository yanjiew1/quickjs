CalendarDateFromFields ( _calendar_: a known calendar type, _fields_: a Calendar Fields Record, _overflow_: *"constrain"* or *"reject"*, ): either a normal completion containing an ISO Date Record or a throw completion

description
It converts a calendar date in the reckoning of _calendar_, if it is uniquely determined by _fields_, into an ISO Date Record.
1. Perform ? CalendarResolveFields(_calendar_, _fields_, ~date~). 1. Let _result_ be ? CalendarDateToISO(_calendar_, _fields_, _overflow_). 1. If ISODateWithinLimits(_result_) is *false*, throw a *RangeError* exception. 1. Return _result_.
