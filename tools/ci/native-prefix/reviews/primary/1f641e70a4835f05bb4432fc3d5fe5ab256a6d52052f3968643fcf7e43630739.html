TimeZoneEquals ( _xTimeZone_: an available time zone identifier, _yTimeZone_: an available time zone identifier, ): a Boolean

description
It returns *true* if its arguments represent time zones using the same identifier.
1. If _xTimeZone_ is _yTimeZone_, return *true*. 1. If _xTimeZone_ is a named time zone identifier and _yTimeZone_ is a named time zone identifier, then 1. Let _xRecord_ be GetAvailableNamedTimeZoneIdentifier(_xTimeZone_). 1. Let _yRecord_ be GetAvailableNamedTimeZoneIdentifier(_yTimeZone_). 1. Assert: _xRecord_ is not ~empty~. 1. Assert: _yRecord_ is not ~empty~. 1. If _xRecord_.[[PrimaryIdentifier]] is _yRecord_.[[PrimaryIdentifier]], return *true*. 1. Assert: If _xTimeZone_ and _yTimeZone_ are both offset time zone identifiers, they do not represent the same number of offset minutes. 1. Return *false*.
