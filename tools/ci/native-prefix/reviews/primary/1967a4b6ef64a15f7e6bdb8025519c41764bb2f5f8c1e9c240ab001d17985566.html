Temporal.PlainDate ( _isoYear_, _isoMonth_, _isoDay_ [ , _calendar_ ] )

This function performs the following steps when called:

1. If NewTarget is *undefined*, throw a *TypeError* exception. 1. Let _year_ be ? SnapToInteger(_isoYear_, ~truncate~). 1. Let _month_ be ? SnapToInteger(_isoMonth_, ~truncate~). 1. Let _day_ be ? SnapToInteger(_isoDay_, ~truncate~). 1. If _calendar_ is *undefined*, set _calendar_ to *"iso8601"*. 1. If _calendar_ is not a String, throw a *TypeError* exception. 1. Set _calendar_ to ? CanonicalizeCalendar(_calendar_). 1. Let _isoDate_ be ? CreateISODateRecord(_year_, _month_, _day_). 1. Return ? CreateTemporalDate(_isoDate_, _calendar_, NewTarget).
