CreatePartsFromList ( _listFormat_: an Intl.ListFormat, _list_: a List of Strings, ): a List of Records with fields [[Type]] (*"element"* or *"literal"*) and [[Value]] (a String)

description
It creates the corresponding List of parts according to the effective locale and the formatting options of _listFormat_.
1. Let _size_ be the number of elements of _list_. 1. If _size_ is 0, then 1. Return a new empty List. 1. If _size_ is 2, then 1. Let _n_ be an index into _listFormat_.[[Templates]] based on _listFormat_.[[Locale]], _list_[0], and _list_[1]. 1. Let _pattern_ be _listFormat_.[[Templates]][_n_].[[Pair]]. 1. Let _first_ be the Record { [[Type]]: *"element"*, [[Value]]: _list_[0] }. 1. Let _second_ be the Record { [[Type]]: *"element"*, [[Value]]: _list_[1] }. 1. Let _placeables_ be the Record { [[0]]: _first_, [[1]]: _second_ }. 1. Return DeconstructPattern(_pattern_, _placeables_). 1. Let _last_ be the Record { [[Type]]: *"element"*, [[Value]]: _list_[_size_ - 1] }. 1. Let _parts_ be « _last_ ». 1. Let _i_ be _size_ - 2. 1. Repeat, while _i_ ≥ 0, 1. Let _head_ be the Record { [[Type]]: *"element"*, [[Value]]: _list_[_i_] }. 1. Let _n_ be an implementation-defined index into _listFormat_.[[Templates]] based on _listFormat_.[[Locale]], _head_, and _parts_. 1. If _i_ is 0, then 1. Let _pattern_ be _listFormat_.[[Templates]][_n_].[[Start]]. 1. Else if _i_ is less than _size_ - 2, then 1. Let _pattern_ be _listFormat_.[[Templates]][_n_].[[Middle]]. 1. Else, 1. Let _pattern_ be _listFormat_.[[Templates]][_n_].[[End]]. 1. Let _placeables_ be the Record { [[0]]: _head_, [[1]]: _parts_ }. 1. Set _parts_ to DeconstructPattern(_pattern_, _placeables_). 1. Set _i_ to _i_ - 1. 1. Return _parts_. The index _n_ to select across multiple templates permits the conjunction to be dependent on the context, as in Spanish, where either "y" or "e" may be selected, depending on the following word.
