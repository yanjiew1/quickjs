GetStartOfDay ( _timeZone_: an available time zone identifier, _isoDate_: an ISO Date Record, ): either a normal completion containing an epoch nanoseconds count or a throw completion

description
It determines the epoch nanoseconds count that corresponds to the first valid wall-clock time in the calendar date _isoDate_ in _timeZone_.
1. Let _isoDateTime_ be the ISO Date-Time Record { [[ISODate]]: _isoDate_, [[Time]]: MidnightTimeRecord() }. 1. Let _possibleEpochNanoseconds_ be ? GetPossibleEpochNanoseconds(_timeZone_, _isoDateTime_). 1. If _possibleEpochNanoseconds_ is not empty, return _possibleEpochNanoseconds_[0]. 1. Assert: _timeZone_ is a named time zone identifier. 1. Let _wallClockAdvance_ be 1. 1. Repeat, 1. Let _timeAfter_ be AddTime(_isoDateTime_.[[Time]], _wallClockAdvance_). 1. Let _isoDateAfter_ be AddDaysToISODate(_isoDate_, _timeAfter_.[[Days]]). 1. Let _isoDateTimeAfter_ be the ISO Date-Time Record { [[ISODate]]: _isoDateAfter_, [[Time]]: _timeAfter_ }. 1. Let _possibleEpochNanosecondsAfter_ be GetNamedTimeZoneEpochNanoseconds(_timeZone_, _isoDateTimeAfter_). 1. If _possibleEpochNanosecondsAfter_ is not empty, then 1. Assert: The number of elements in _possibleEpochNanosecondsAfter_ = 1. 1. Let _result_ be the sole element of _possibleEpochNanosecondsAfter_. 1. If IsWithinEpochNanosecondsInterval(_result_) is *false*, throw a *RangeError* exception. 1. Return _result_. 1. Set _wallClockAdvance_ to _wallClockAdvance_ + 1.
