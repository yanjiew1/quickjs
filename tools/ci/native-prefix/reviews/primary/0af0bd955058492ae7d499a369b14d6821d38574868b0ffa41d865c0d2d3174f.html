GetTemporalOverflowOption ( _options_: an Object, ): either a normal completion containing either *"constrain"* or *"reject"*, or a throw completion

description
It fetches and validates the *"overflow"* property of _options_, returning *"constrain"* if absent.
1. Let _value_ be ? Get(_options_, *"overflow"*). 1. If _value_ is *undefined*, return *"constrain"*. 1. Let _stringValue_ be ? ToString(_value_). 1. If _stringValue_ is not one of *"constrain"* or *"reject"*, throw a *RangeError* exception. 1. Return _stringValue_.
